Mystica 隐私政策

生效日期：2026-11-24

联系邮箱：albert_lqchen@hotmail.com

Mystica 是一款供静思与消遣的 iPhone App。本政策用平实的话说明：App 在你的手机上保存什么、什么情况下会有数据离开手机、由谁接收。本政策适用于 1.0 版本。

简短地说：我们没有为这款 App 运营任何服务器，也不会收到你的任何数据。 App 没有账号、没有广告、没有统计分析、没有跟踪，我们绝不出售数据。默认情况下，一切都留在你的手机上。只有下文「何时、向谁发送什么」所列的三种情况，数据才会离开手机。

我们是谁

Mystica 由 Liqun Chen 发布。你可以通过 albert_lqchen@hotmail.com 联系我们。

留在你手机上的内容

  • 出生资料（姓名、出生日期与时间、出生地）：仅当你为需要它的占问方法填写时才会保存，存放在 iOS 钥匙串中，而不是普通文件。
  • API 密钥：仅当你填入自己的云端密钥时才会保存，存放在 iOS 钥匙串中，设备首次解锁后才可在本机读取，绝不写入日志或普通偏好设置。
  • 札记：你保存的解读（你的问题、抽出的诸象、解读文字、追问对话与灯火提示）。它是 App 私有存储中的一个文件，启用 iOS 文件保护，并且不包含在设备备份中。
  • 偏好设置：如语言、触感反馈、灯火设置。
  • 语音：音频只在你口述时使用，在手机上转成文字，不会保存。保留下来的只有文字，如同你亲手输入。
  • 手相照片：解读期间保存在内存中，会被缩小尺寸，App 不会另存（离开解读画面后 App 不再保留副本；但你自己的相册或相机胶卷可能保留）。

默认情况下，解读由 Apple 的本地模型生成，所以你的问题和抽出的诸象都在手机上处理，不会传输出去。

何时、向谁发送什么

  1. 可选的云端解读（默认关闭）。 只有当你在 App 中选择 Claude（Anthropic）或 OpenAI、在「使用云端解读之前」画面中点「同意并继续」，并填入你自己的 API 密钥后，App 才会通过 HTTPS 从你的手机直接向该公司的服务器发出请求。请求内容包括：你的问题；抽出的诸象及其释义（对依据出生信息的方法，这包括由出生信息推算出的结果，例如星盘位置或命理数字，但绝不包括你的姓名、出生日期、出生时间或出生地本身）；你就该次解读提出的追问；所用语言；以及仅限手相占问时的手相照片。「测试密钥」按钮只会发出一次极小的、不含任何解读资料的请求。我们不运营任何中转服务器：请求由你的手机凭你的密钥直接发给服务商，费用计入你在该服务商的账户。
  2. 出生地搜索。 当你输入城市作为出生地时，你输入的文字（两个字符以上）会发送给 Apple 地图（MapKit），用来查找匹配的地点，并受 Apple 自己的条款约束。
  3. 语音识别。 如果你使用麦克风按钮，Apple 的语音识别只在你的设备上运行。App 要求必须在设备上识别，绝不使用服务器。若你的设备无法在本机识别你的语言，该按钮会显示为不可用。

除此之外，App 不会传输任何其他内容。即使你开启了云端解读，灯火提示也始终在设备上生成（或使用 App 内置的固定文字）。当你点击「获取密钥」等链接或致谢中的链接时，你会离开 App 前往对应网站，该网站有它自己的政策。

我们绝不做的事

  • 没有账号，无需登录。
  • 没有广告，没有广告网络。
  • App 内没有统计分析或崩溃回报组件，也不跨 App 或网站跟踪你。
  • 不出售、出租或分享你的数据。我们本来就不会收到。
  • 没有内购。

（如果你在 iOS 设置中同意分享，Apple 可能向开发者提供汇总的、匿名的崩溃与使用统计。那是 Apple 系统的功能，并非 App 收集。）

你的控制权

  • 删除札记： 札记画面 > 全部删除（也可单独删除某一条）。
  • 移除密钥： 静室 > 密钥区块 > 移除密钥，会把它从钥匙串中删除。
  • 关闭云端： 在静室中关闭「已允许云端解读」，解读即回到本地模型。
  • 全部清除： 在静室点「清除我的全部数据」，即可一次性从手机上移除你的出生资料、两把已保存的 API 密钥、云端设置与整本札记。你也可以随时在静室或填写画面更改已保存的出生信息。删除 App 会移除它的文件，但 iOS 可能在删除 App 后仍保留钥匙串项目；如果你在意，请先使用「清除我的全部数据」。
  • 权限： 你可随时在 iOS「设置 > Mystica」中撤回相机、照片、麦克风或语音识别权限。

第三方及其政策

使用可选功能时，下列公司会依其自身条款处理数据：

  • Anthropic（Claude）：https://www.anthropic.com/legal/privacy
  • OpenAI：https://openai.com/policies/privacy-policy
  • Apple（Apple 地图、本地语音、Apple Intelligence）：https://www.apple.com/legal/privacy/

你发送给它们的请求会保存多久，我们无法控制，请查阅它们的 API 数据保留条款。

保留期限

我们不保留任何数据，因为我们根本不会收到。你的数据留在你的手机上，直到你删除。你选用的服务商会适用它们自己的保留政策。

儿童

Mystica 并非面向 13 岁以下儿童，我们也不会有意收集任何人的个人信息。App 在 App Store 的年龄分级反映其内容（涉及神秘学与占卜主题）。如果你是家长，并认为孩子在 App 中输入了个人资料，这些资料只保存在那台设备上，可按上文方式删除。

供消遣，不构成建议

Mystica 的解读是由象征编织的故事，供静思与消遣。它们并非预言，也不构成医疗、法律、财务或心理方面的建议。

政策变更

如果 App 处理数据的方式发生变化（例如将来增加服务器），我们会更新本页并修改上方的生效日期；若变更重要，会在新行为生效前于版本说明中告知。
